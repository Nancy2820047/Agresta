
# Environment Sensor Module

This module handles temperature and humidity monitoring for Agresta using the DHT22 sensor.

## Responsibilities

- Read temperature and humidity measurements.
- Validate sensor readings and handle errors.
- Provide timestamped measurements.
- Follow the DHT22's supported sampling interval.
- Support concurrent sensor acquisition.
- Prepare environmental data for the Decision Support System.

## Hardware

- Raspberry Pi
- DHT22 temperature and humidity sensor
- Jumper wires
- Pull-up resistor, if required by the sensor module
