
# Web Dashboard

This module contains Agresta's web-based monitoring and decision-support interface.

## Responsibilities

- Display real-time feed, water, temperature, and humidity measurements.
- Visualize historical sensor data.
- Present resource consumption trends.
- Display shortage predictions and anomaly alerts.
- Show Decision Support System recommendations and supporting evidence.
- Allow users to review and acknowledge alerts.
- Indicate sensor connectivity and system status.

## Planned Technologies

- Web-based user interface
- HTTP REST API
- WebSocket for real-time updates

## Planned Dashboard Sections

### 1. Farm Overview
Summary of current resource availability and environmental conditions.

### 2. Feeding Monitoring
Feed weight, historical measurements, and replenishment estimates.

### 3. Water Monitoring
Tank level, water flow, and possible water-loss events.

### 4. Environment Monitoring
Temperature, humidity, and environmental alerts.

### 5. Decision Support
Predictions, detected anomalies, explanations, and recommended actions.

## Phase 1 Deliverables

- Define dashboard requirements.
- Prepare a simple interface concept.
- Support the display of actual sensor readings.

## Phase 2 Deliverables

- Implement the complete web interface.
- Integrate the dashboard with the backend.
- Display real-time readings using WebSocket.
- Retrieve historical data through HTTP.
- Present Decision Support System outputs.
- Test usability and reliability.
