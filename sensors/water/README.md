
# Water Sensor Module

This module handles water-level and water-flow monitoring for Agresta.

## Responsibilities

- Measure water-tank levels using an ultrasonic sensor.
- Measure water flow through a flow sensor.
- Calibrate and validate sensor measurements.
- Provide timestamped water-level and flow readings.
- Prepare measurements for water-loss analysis.
- Support concurrent sensor acquisition.

## Hardware

- Raspberry Pi
- HC-SR04 ultrasonic sensor
- YF-S201 water-flow sensor
- Safe voltage-level interfacing components
