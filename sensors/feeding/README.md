# Feeding Sensor Module

This module handles feed-weight monitoring
using a load cell and HX711 amplifier.

## Responsibilities

- Read feed-weight measurements.
- Calibrate the load cell.
- Validate sensor readings.
- Provide timestamped measurements.
- Support concurrent sensor acquisition.

## Hardware

- Raspberry Pi
- 5 kg load cell
- HX711 amplifier module
